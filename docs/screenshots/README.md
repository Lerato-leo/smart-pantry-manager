# Dijong screenshots

Screenshots of the running app on a Pixel emulator (Android 17, 1080 × 2424), in the order
someone would use it. Files are named `NN-screen-state.png`: a two-digit number so they sort in
that order, the screen, then what it shows.

| File | What it shows |
|---|---|
| `01-launcher-icon.png` | The Dijong pot icon on the home screen (bottom right). |
| `02-pantry-empty.png` | The main page before anything is added: the empty-pantry illustration and a hint to tap +. |
| `03-add-ingredient-form.png` | The empty Add ingredient form: name, quantity, unit, category and optional expiry date. |
| `04-add-ingredient-validation-error.png` | Validation: saving without a quantity shows "Enter a quantity above 0" under the field. |
| `05-add-ingredient-unit-menu.png` | The unit menu, showing four units at a time and scrolling for the rest. |
| `06-add-ingredient-category-menu.png` | The category menu, each category with its colour. |
| `07-add-ingredient-date-picker.png` | Picking an expiry date from the calendar. |
| `08-add-ingredient-completed.png` | A filled-in form, with the "Expires in 2 days" badge under the date. |
| `09-pantry-ingredient-added.png` | Back on the main page after saving (Create): the new card and an "Ingredient added" message with Undo. |
| `10-pantry-list.png` | The pantry list (Read): category icons and chips, expiry badges, expiring items first, and the "17 ingredients · 2 expiring soon" count. |
| `11-edit-ingredient.png` | Editing an item (Update), with the Delete ingredient button. |
| `12-pantry-ingredient-deleted.png` | After swiping a card away (Delete): "Baked beans deleted" with Undo. |
| `13-cook-empty.png` | What Can I Cook with nothing that matches: the empty-pot illustration and an Add ingredients button. |
| `14-cook-suggestions.png` | What Can I Cook: two recipes ready to cook, and the separate Almost there panel saying what each is short of. |
| `15-recipe-ready.png` | A recipe you can cook now: every ingredient ticked and the numbered method. |
| `16-recipe-missing-ingredient.png` | A recipe one ingredient short: the bread loaf is marked "Missing". |
| `17-recipe-not-enough.png` | A recipe where there's some butternut but not enough, marked "Not enough". |
| `18-recipe-expired-ingredient.png` | A recipe held back by expired food: the chicken is marked "Expired", since expired stock never counts. |
| `19-settings.png` | Settings: expiring-soon alerts, the Almost There switch, metric or imperial units, and Reset sample recipes. |
| `20-recipe-imperial-units.png` | The same recipe as 17 with Imperial chosen: amounts in lb and fl oz. |
